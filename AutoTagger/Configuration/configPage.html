Auto Tagger

Enter comma-separated tags for each library. Items added to that library are tagged automatically. Leave a library blank to skip it. Tagging is additive: existing tags are never removed.

If an item already carries one of a library's skip tags, that library's tags are not applied to it. Listing the same tag in both boxes makes the library tag its items once and then leave them alone.

To apply tags to items that are already in a library, run Apply auto-tags to existing items from Dashboard → Scheduled Tasks.
